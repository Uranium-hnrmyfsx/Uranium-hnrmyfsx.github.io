# 安装之前...
笔者假设你现在有一块空闲的固态（或是你已经决定不要上面的数据的固态）以及一个8gb+的U盘，当然还有两只手和一个脑子、一台配件齐全的电脑。
## 下载光盘镜像
不要问我为什么是`光盘`镜像。
首先笔者认为你现在有一台能用的电脑。
访问[debian.org](https://www.debian.org)。
接下来看图操作：![⚠️注意一定选其他下载链接](/img/1/1.png)
建议选择完整安装镜像1️⃣。如果你家网速支持，那么可以选择小型安装镜像2️⃣（网络安装）。
⚠️如果仅用于安装，一定不要选现场版安装镜像3️⃣！对于中国用户，这个镜像安装完的系统会有很多不必要的软件和功能（比如日文输入法，支持韩文的终端），而且有些卸载很麻烦！
![找找1️⃣2️⃣3️⃣](/img/1/2.png)
